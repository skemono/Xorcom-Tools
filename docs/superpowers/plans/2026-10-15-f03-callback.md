# F-03 Devolución de llamada Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third tool, F-03, that installs and removes the Xorcom automated queue callback on the active CompletePBX 5 (Call Center only). It covers the dialplan file and log over SSH, plus the custom app, breakout IVR, per-queue Queue Priority + priority app, and queue IVR + `membergosub` through the portal API. Every change is previewed, applied in a safe order, and read back.

**Architecture:** Pure functions in `pbx` own the settings, the generated dialplan, the PBX state model and the install/remove plans, and are unit-tested. One SSH session reads the whole state; small SSH commands write the file, the log and the dropped callbacks; a portal session writes the portal objects. A thin bound `CallbackService` keeps the last preview and re-plans against a fresh read before Aplicar, so it writes exactly what was previewed or refuses. The F-03 Svelte sheet follows `Pines.svelte`.

**Tech Stack:** Go 1.26, Wails v3.0.0-beta.28, Svelte 5 + TS, `golang.org/x/crypto/ssh` (client and, in tests, server), `net/http` + `mime/multipart` (portal), `net/http/httptest` (fake portal in tests).

## Review Focus

1. **The PBX changes between Vista previa and Aplicar** (someone edits the queue in the portal, a callback request arrives): Aplicar must re-read the PBX and refuse with "la PBX cambió desde la vista previa" instead of applying a stale plan. → `TestCallbackApplyRefusesChangedPBX` (Task 7).
2. **A previous Aplicar stopped halfway** (app and IVR exist, queue not attached): the next preview creates only the missing pieces, and running it again stamps everything OMITIDO. → `TestPlanInstallResumesPartial` (Task 4).
3. **The callback file was edited by hand or lost its settings header:** Estado shows "distinto". Quitar on one of several queues refuses to regenerate it without settings and says to reinstall. → `TestParseCallbackConfig` (Task 2) and `TestPlanRemoveNeedsConfig` (Task 4).
4. **The chosen recording was deleted in the portal after it was picked:** the preview fails with a clear message instead of writing a `Playback()` of a missing file. → `TestPlanInstallMissingRecording` (Task 4).
5. **Dial-code collisions:** app code 799 is already an extension or ring group, or 797 is taken. The callback app step blocks with the code named, and priority apps take the next free code down. → `TestPlanInstallCodeCollision` (Task 4).

```go
package pbx

import (
	"encoding/json"
	"errors"
	"fmt"
	"regexp"
	"strconv"
	"strings"
)

// CallbackConfig holds the F-03 settings. Defaults follow the Xorcom article.
type CallbackConfig struct {
	Key        string `json:"key"`        // the key a waiting caller presses
	AppCode    string `json:"appCode"`    // custom app that runs create_callback
	Priority   int    `json:"priority"`   // queue priority of a returned call
	Retries    int    `json:"retries"`    // .call MaxRetries
	RetrySecs  int    `json:"retrySecs"`  // .call RetryTime
	RingSecs   int    `json:"ringSecs"`   // .call WaitTime
	CallerName string `json:"callerName"` // caller ID name the agent sees
	Prefix     string `json:"prefix"`     // digits dialed before the caller's number
	Recording  int    `json:"recording"`  // ombu_recordings id played after the key, 0 = none
}

func DefaultCallbackConfig() CallbackConfig {
	return CallbackConfig{Key: "0", AppCode: "799", Priority: 10, Retries: 2, RetrySecs: 1800, RingSecs: 30, CallerName: "Call Back"}
}

var (
	reDigits     = regexp.MustCompile(`^[0-9]+$`)
	reCallerName = regexp.MustCompile(`^[A-Za-z0-9 ]{1,30}$`)
)

// Validate checks every value that ends up in the dialplan or a shell command. Messages are shown to the user.
func (c CallbackConfig) Validate() error {
	in := func(v, lo, hi int) bool { return v >= lo && v <= hi }
	switch {
	case len(c.Key) != 1 || !strings.Contains("0123456789*#", c.Key):
		return errors.New("la tecla debe ser un dígito, * o #")
	case !reDigits.MatchString(c.AppCode) || len(c.AppCode) > 8:
		return errors.New("el código de la aplicación debe tener de 1 a 8 dígitos")
	case !in(c.Priority, 1, 99):
		return errors.New("la prioridad debe estar entre 1 y 99")
	case !in(c.Retries, 0, 10):
		return errors.New("los reintentos deben estar entre 0 y 10")
	case !in(c.RetrySecs, 60, 86400):
		return errors.New("el intervalo entre reintentos debe estar entre 60 y 86 400 segundos")
	case !in(c.RingSecs, 10, 120):
		return errors.New("el tiempo de timbre debe estar entre 10 y 120 segundos")
	case !reCallerName.MatchString(c.CallerName):
		return errors.New("el nombre para el agente solo admite letras sin tilde, números y espacios (máx. 30)")
	case len(c.Prefix) > 6 || c.Prefix != "" && !reDigits.MatchString(c.Prefix):
		return errors.New("el prefijo solo admite de 0 a 6 dígitos")
	case c.Recording < 0:
		return errors.New("grabación inválida")
	}
	return nil
}

// CheckDialNumber validates the route-check number before it reaches an asterisk -rx command line.
func CheckDialNumber(n string) error {
	if !reDigits.MatchString(n) || len(n) < 3 || len(n) > 20 {
		return fmt.Errorf("el número de prueba «%s» debe tener de 3 a 20 dígitos", n)
	}
	return nil
}

// CallbackRoute sends a called-back customer of Queue to App, the custom app of its Queue Priority.
type CallbackRoute struct {
	Queue string `json:"queue"`
	App   string `json:"app"`
}

const callbackHeader = "; f03-config: "

// CallbackDialplan renders extensions__65-callback.conf. c must be valid; playback is a path from
// CallbackState.RecordingPath ("" = none); routes come from the plans (digits only). The settings travel
// in a header line, so Estado and Quitar can read back what was installed.
func CallbackDialplan(c CallbackConfig, playback string, routes []CallbackRoute) string {
	cfg, _ := json.Marshal(c)
	play := ""
	if playback != "" {
		play = " same => n,Playback(" + playback + ")\n"
	}
	var rt strings.Builder
	for _, r := range routes {
		fmt.Fprintf(&rt, " same => n,GotoIf($[\"${QUEUE_NUMBER}\"=\"%s\"]?cos-all,%s,1)\n", r.Queue, r.App)
	}
	return strings.NewReplacer(
		"«config»", string(cfg),
		"«prefix»", c.Prefix,
		"«ring»", strconv.Itoa(c.RingSecs),
		"«retries»", strconv.Itoa(c.Retries),
		"«retry»", strconv.Itoa(c.RetrySecs),
		"«name»", c.CallerName,
		"«playback»\n", play,
		"«routes»\n", rt.String(),
	).Replace(callbackTemplate)
}

// ParseCallbackConfig reads the settings back from an installed file; false when the header is
// missing or does not validate (a hand-edited or foreign file).
func ParseCallbackConfig(file string) (CallbackConfig, bool) {
	for _, line := range strings.Split(file, "\n") {
		if rest, ok := strings.CutPrefix(line, callbackHeader); ok {
			var c CallbackConfig
			if json.Unmarshal([]byte(rest), &c) != nil || c.Validate() != nil {
				return CallbackConfig{}, false
			}
			return c, true
		}
	}
	return CallbackConfig{}, false
}
```

```go
type CallbackState struct {

// destJoin resolves an ombu_destinations id column to (dest_kind, dest_index).
func destJoin(col string) string {
	return " LEFT JOIN ombu_destinations d ON d.destination_id = " + col +
		" LEFT JOIN ombu_destination_categories c ON c.category_id = d.category_id"
}

var callbackSQL = []struct{ name, sql string }{

// callbackStateScript reads the whole state; every section starts with "@@f03 <name>". codes must be digits.
func callbackStateScript(codes []string) string {
	var b strings.Builder
	for _, q := range callbackSQL {
		fmt.Fprintf(&b, "echo '%s%s'\n%s <<'SQL'\n%s\nSQL\n", sectionMark, q.name, mysqlCmd, q.sql)
	}
	fmt.Fprintf(&b, "echo '%srecdir'\nls -d /var/lib/ombutel/static/*/recordings 2>/dev/null\n", sectionMark)
	fmt.Fprintf(&b, "echo '%sfile'\nif [ -e %s ]; then echo 1; base64 -w0 %s; echo; fi\n", sectionMark, callbackFile, callbackFile)
	fmt.Fprintf(&b, "echo '%slog'\nstat -c %%U %s 2>/dev/null\n", sectionMark, callbackLog)
	fmt.Fprintf(&b, "echo '%scontexts'\nfor c in create_callback check_position callback_out; do asterisk -rx \"dialplan show $c\" | grep -q \"Context '$c'\" && echo $c; done\n", sectionMark)
	fmt.Fprintf(&b, "echo '%staken'\nfor c in %s; do asterisk -rx \"dialplan show $c@cos-all-local\" | grep -q 'There is no existence' || echo $c; done\n", sectionMark, strings.Join(codes, " "))

}

// ReadCallbackState runs the state script over SSH. codes are the dial codes to check (CandidateCodes).
func ReadCallbackState(ctx context.Context, p Profile, sec Secrets, codes []string) (CallbackState, error) {
	for _, c := range codes {
		if !reDigits.MatchString(c) {
			return CallbackState{}, fmt.Errorf("código inválido «%s»", c)
		}
	}
	if len(codes) == 0 {
		codes = []string{"0"} // keeps the for loop valid; "0" is never a free app code anyway
	}
	out, err := SSHExec(ctx, p, sec.SSH, sec.SSHKey, "bash -s", strings.NewReader(callbackStateScript(codes)))
	if err != nil {
		return CallbackState{}, fmt.Errorf("no se pudo leer el estado de la PBX: %w", err)
	}
	return parseCallbackState(out)
}

var reWaiting = regexp.MustCompile(`^/[^/]+/callback/([0-9]+)/([0-9]+\.[0-9]+)\s*:\s*(\S*)`)

func parseCallbackState(out string) (CallbackState, error) {
	sec := map[string]string{}
	name := ""
	for _, line := range strings.SplitAfter(out, "\n") {
		if n, ok := strings.CutPrefix(line, sectionMark); ok {
			name = strings.TrimSpace(n)
			sec[name] = ""
			continue
		}
		if name != "" {
			sec[name] += line
		}
	}
	if _, ok := sec["waiting"]; !ok {
		return CallbackState{}, errors.New("respuesta inesperada de la PBX al leer el estado (¿es una CompletePBX 5?)")
	}
	atoi := func(s string) int { n, _ := strconv.Atoi(s); return n }
	lines := func(s string) []string { return strings.Fields(s) }
	st := CallbackState{TakenCodes: map[string]bool{}}
	for _, r := range parseBatch(sec["modules"]) {
		st.HasCC = st.HasCC || r["name"] == "supervision"
	}
	for _, r := range parseBatch(sec["queues"]) {
		st.Queues = append(st.Queues, CallbackQueue{ID: atoi(r["id"]), Extension: r["extension"], Description: r["description"],
			IVRID: atoi(r["ivr_id"]), IVRName: r["ivr_name"], MemberGosub: r["membergosub"]})
	}
	for _, r := range parseBatch(sec["apps"]) {
		st.Apps = append(st.Apps, CallbackApp{ID: atoi(r["id"]), Extension: r["extension"], Description: r["description"],
			DestKind: r["dest_kind"], DestIndex: atoi(r["dest_index"]), Custom: r["custom"]})
	}
	for _, r := range parseBatch(sec["ivrs"]) {
		id := atoi(r["id"])
		if n := len(st.IVRs); n == 0 || st.IVRs[n-1].ID != id {
			st.IVRs = append(st.IVRs, CallbackIVR{ID: id, Description: r["description"]})
		}
		if r["option"] != "" || r["dest_kind"] != "" {
			iv := &st.IVRs[len(st.IVRs)-1]
			iv.Entries = append(iv.Entries, CallbackIVREntry{Option: r["option"], Enabled: r["enabled"] == "yes", DestKind: r["dest_kind"], DestIndex: atoi(r["dest_index"])})
		}
	}
	for _, r := range parseBatch(sec["priorities"]) {
		st.Priorities = append(st.Priorities, CallbackPriority{ID: atoi(r["id"]), Description: r["description"], Priority: atoi(r["priority"]),
			DestKind: r["dest_kind"], DestIndex: atoi(r["dest_index"])})
	}
	for _, r := range parseBatch(sec["recordings"]) {
		st.Recordings = append(st.Recordings, CallbackRecording{ID: atoi(r["id"]), Name: r["name"]})
	}
	if d := lines(sec["recdir"]); len(d) == 1 { // exactly one portal instance dir, or no playback
		st.RecordingDir = d[0]
	}
	if f := lines(sec["file"]); len(f) >= 1 && f[0] == "1" {
		st.FileExists = true
		if len(f) == 2 {
			raw, err := base64.StdEncoding.DecodeString(f[1])
			if err != nil {
				return CallbackState{}, fmt.Errorf("no se pudo leer %s: %v", callbackFile, err)
			}
			st.File = string(raw)
		}
	}
	if o := lines(sec["log"]); len(o) == 1 {
		st.LogOwner = o[0]
	}
	st.Contexts = len(lines(sec["contexts"]))
	for _, c := range lines(sec["taken"]) {
		st.TakenCodes[c] = true
	}
	for _, line := range strings.Split(sec["waiting"], "\n") {
		if m := reWaiting.FindStringSubmatch(strings.TrimSpace(line)); m != nil {
			st.Waiting = append(st.Waiting, CallbackWaiting{Queue: m[1], ID: m[2], Number: m[3]})
		}
	}
	return st, nil
}
```

```go
package pbx

import (

// Statuses: before Aplicar/Quitar (nuevo/omitir/bloqueado) and after (aplicado/omitido/fallo/no_ejecutado).
const (
	CbNew     = "nuevo"
	CbSkip    = "omitir"
	CbBlocked = "bloqueado"
	CbApplied = "aplicado"
	CbSkipped = "omitido"
	CbFailed  = "fallo"
	CbNotRun  = "no_ejecutado"
)

// Step kinds. Install runs file, log, app, ivr, then per queue priority, prioapp, queue (the step that
// touches live calls last). Quitar runs per queue detach, delprioapp, delpriority, dropwaiting, then the shared pieces.
const (
	StepFile        = "file"
	StepLog         = "log"
	StepApp         = "app"
	StepIVR         = "ivr"
	StepPriority    = "priority"
	StepPrioApp     = "prioapp"
	StepQueue       = "queue"
	StepDetach      = "detach"
	StepDelPrioApp  = "delprioapp"
	StepDelPriority = "delpriority"
	StepDropWaiting = "dropwaiting"
	StepDelIVR      = "delivr"
	StepDelApp      = "delapp"
	StepDelFile     = "delfile"
)

const (
	callbackTarget = "create_callback,s,1"
	memberGosub    = "check_position"
	firstPrioCode  = 797
	lastPrioCode   = 748
)

// CallbackStep is one line of the preview and of the result.
type CallbackStep struct {
	Kind   string `json:"kind"`
	Queue  string `json:"queue"` // queue extension, for per-queue steps
	Code   string `json:"code"`  // app code, for app steps
	Label  string `json:"label"`
	Before string `json:"before"`
	After  string `json:"after"`
	Status string `json:"status"`
	Error  string `json:"error"`
}

// CallbackPlan is exactly what Aplicar/Quitar will do: the steps in run order and the file content.
type CallbackPlan struct {
	Remove      bool            `json:"remove"`
	DropWaiting bool            `json:"dropWaiting"`
	Config      CallbackConfig  `json:"config"`
	Queues      []string        `json:"queues"`
	Routes      []CallbackRoute `json:"routes"`
	Dialplan    string          `json:"dialplan"`
	Steps       []CallbackStep  `json:"steps"`
}

// CandidateCodes are the dial codes ReadCallbackState checks: the callback app's, then the priority range.
func CandidateCodes(appCode string) []string {
	codes := []string{appCode}
	for n := firstPrioCode; n >= lastPrioCode; n-- {
		if c := strconv.Itoa(n); c != appCode {
			codes = append(codes, c)
		}
	}
	return codes
}

// RecordingPath is where the IVRs play recording id from (the portal names it md5 of the id), or "".
func (st CallbackState) RecordingPath(id int) string {
	if id == 0 || st.RecordingDir == "" {
		return ""
	}
	for _, r := range st.Recordings {
		if r.ID == id {
			path := fmt.Sprintf("%s/%x", st.RecordingDir, md5.Sum([]byte(strconv.Itoa(id))))
			if rePlayback.MatchString(path) {
				return path
			}
		}
	}
	return ""
}

var rePlayback = regexp.MustCompile(`^/var/lib/ombutel/static/[A-Za-z0-9]+/recordings/[0-9a-f]{32}$`)

// CallbackApp is F-03's custom app: the one whose destination is Custom create_callback,s,1.
func (st CallbackState) CallbackApp() *CallbackApp {
	for i := range st.Apps {
		if st.Apps[i].DestKind == "custom" && st.Apps[i].Custom == callbackTarget {
			return &st.Apps[i]
		}
	}
	return nil
}

// CallbackIVR is F-03's breakout IVR: one entry, going to the callback app.
func (st CallbackState) CallbackIVR() *CallbackIVR {
	app := st.CallbackApp()
	if app == nil {
		return nil
	}
	for i := range st.IVRs {
		e := st.IVRs[i].Entries
		if len(e) == 1 && e[0].DestKind == "custom_application" && e[0].DestIndex == app.ID {
			return &st.IVRs[i]
		}
	}
	return nil
}

func (st CallbackState) Queue(ext string) *CallbackQueue {
	for i := range st.Queues {
		if st.Queues[i].Extension == ext {
			return &st.Queues[i]
		}
	}
	return nil
}

// Priority is queue q's callback Queue Priority: "Callback <ext>", going to q.
func (st CallbackState) Priority(q CallbackQueue) *CallbackPriority {
	for i := range st.Priorities {
		p := st.Priorities[i]
		if p.DestKind == "queue" && p.DestIndex == q.ID && p.Description == "Callback "+q.Extension {
			return &st.Priorities[i]
		}
	}
	return nil
}

// PrioApp is the custom app going to Queue Priority pr.
func (st CallbackState) PrioApp(pr *CallbackPriority) *CallbackApp {
	if pr == nil {
		return nil
	}
	for i := range st.Apps {
		if st.Apps[i].DestKind == "queue_priority" && st.Apps[i].DestIndex == pr.ID {
			return &st.Apps[i]
		}
	}
	return nil
}

// Attached: q breaks out to the callback IVR and runs check_position.
func (st CallbackState) Attached(q CallbackQueue) bool {
	iv := st.CallbackIVR()
	return iv != nil && q.IVRID == iv.ID && q.MemberGosub == memberGosub
}

// hooked: q carries any part of F-03 (the callback IVR or check_position), so Quitar must detach it.
func (st CallbackState) hooked(q CallbackQueue) bool {
	iv := st.CallbackIVR()
	return iv != nil && q.IVRID == iv.ID || q.MemberGosub == memberGosub
}

// foreign is why F-03 must not touch q ("" = it may): an IVR or a membergosub that is not F-03's.
func (st CallbackState) foreign(q CallbackQueue) string {
	ivr := st.CallbackIVR()
	switch {
	case q.IVRID != 0 && (ivr == nil || q.IVRID != ivr.ID):
		return fmt.Sprintf("la cola ya tiene el IVR «%s»: F-03 no lo reemplaza", q.IVRName)
	case q.MemberGosub != "" && q.MemberGosub != memberGosub:
		return fmt.Sprintf("la cola ya tiene membergosub «%s»: F-03 no lo reemplaza", q.MemberGosub)
	}
	return ""
}

// CallbackQueueView is one queue as the sheet shows it; the rules stay here, not in the UI.

	Attached bool          `json:"attached"` // callback fully on
	Hooked   bool          `json:"hooked"`   // any F-03 part on: Quitar can take it off
	Foreign  string        `json:"foreign"`  // why Instalar must skip it, "" = it can take callback

func (st CallbackState) codeTaken(code string) bool {
	if st.TakenCodes[code] {
		return true
	}
	for _, a := range st.Apps {
		if a.Extension == code {
			return true
		}
	}
	for _, q := range st.Queues {
		if q.Extension == code {
			return true
		}
	}
	return false

	n := 0
	for _, w := range st.Waiting {
		if w.Queue == queue {
			n++
		}
	}

// step builds a plan line; a block wins over done (leftovers on a foreign queue are not "installed").
func step(kind, queue, code, label, before, after string, done bool, block string) CallbackStep {
	s := CallbackStep{Kind: kind, Queue: queue, Code: code, Label: label, Before: before, After: after, Status: CbNew}
	switch {
	case block != "":
		s.Status, s.Error = CbBlocked, block
	case done:
		s.Status, s.After = CbSkip, "ya instalado: se omite"
	}
	return s
}

func or(s, empty string) string {
	if s == "" {
		return empty
	}
	return s
}

func queueNow(q CallbackQueue) string {

// fileStep compares the installed file with want. Equal content counts as installed only if Asterisk
// has the 3 contexts loaded; otherwise the step rewrites it and reloads.
func fileStep(st CallbackState, want string) CallbackStep {
	before := "no existe"
	if st.FileExists {
		before = "distinto: se reemplaza"
		if st.File == want {
			before = "igual"
		}
	}
	return step(StepFile, "", "", "Archivo extensions__65-callback.conf", before, "contenido de la vista previa", st.FileExists && st.File == want && st.Contexts == 3, "")
}

// PlanInstall lists every step Aplicar takes to put callback on queues, in run order.
func PlanInstall(st CallbackState, c CallbackConfig, queues []string) (CallbackPlan, error) {
	if !st.HasCC {
		return CallbackPlan{}, errors.New("esta PBX no tiene Call Center: la devolución de llamada necesita el módulo del Call Center")
	}
	if err := c.Validate(); err != nil {
		return CallbackPlan{}, err
	}
	if len(queues) == 0 {
		return CallbackPlan{}, errors.New("elija al menos una cola")
	}
	playback := st.RecordingPath(c.Recording)
	if c.Recording != 0 && playback == "" {
		return CallbackPlan{}, errors.New("la grabación elegida ya no existe en la PBX: vuelva a leer el estado")
	}
	app, ivr := st.CallbackApp(), st.CallbackIVR()
	used := map[string]bool{c.AppCode: true}
	next := firstPrioCode
	take := func() string {
		for ; next >= lastPrioCode; next-- {
			if code := strconv.Itoa(next); !used[code] && !st.codeTaken(code) {
				used[code] = true
				next--
				return code
			}
		}
		return ""
	}
	selected := map[string]bool{}
	var routes []CallbackRoute
	var perQueue []CallbackStep
	for _, ext := range queues {
		q := st.Queue(ext)
		if q == nil {
			return CallbackPlan{}, fmt.Errorf("la cola %s no existe en la PBX", ext)
		}
		if selected[ext] {
			continue
		}
		selected[ext] = true
		block := st.foreign(*q)
		pr := st.Priority(*q)
		pa := st.PrioApp(pr)
		code := ""
		switch {
		case pa != nil:
			code = pa.Extension
		case block == "":
			if code = take(); code == "" {
				block = fmt.Sprintf("no hay códigos libres entre %d y %d para la aplicación de prioridad", firstPrioCode, lastPrioCode)
			}
		}
		if block == "" {
			routes = append(routes, CallbackRoute{Queue: ext, App: code})
		}
		name := "Callback " + ext
		perQueue = append(perQueue,
			step(StepPriority, ext, "", fmt.Sprintf("Prioridad de cola «%s»", name), or(map[bool]string{true: "existe"}[pr != nil], "no existe"),
				fmt.Sprintf("prioridad %d → cola %s", c.Priority, ext), pr != nil, block),
			step(StepPrioApp, ext, code, fmt.Sprintf("Aplicación %s «%s»", or(code, "—"), name), or(map[bool]string{true: "existe"}[pa != nil], "no existe"),
				fmt.Sprintf("→ prioridad «%s»", name), pa != nil, block),
			step(StepQueue, ext, "", fmt.Sprintf("Cola %s · %s", ext, q.Description), queueNow(*q),
				"IVR: Callback · membergosub: "+memberGosub, st.Attached(*q), block))
	}
	for _, q := range st.Queues { // queues that already have callback keep their callback_out line
		if !selected[q.Extension] && st.Attached(q) {
			if pa := st.PrioApp(st.Priority(q)); pa != nil {
				routes = append(routes, CallbackRoute{Queue: q.Extension, App: pa.Extension})
			}
		}
	}
	sort.Slice(routes, func(i, j int) bool { return routes[i].Queue < routes[j].Queue })
	plan := CallbackPlan{Config: c, Queues: queues, Routes: routes, Dialplan: CallbackDialplan(c, playback, routes)}
	appBlock := ""
	if app == nil && st.codeTaken(c.AppCode) {
		appBlock = fmt.Sprintf("el código %s ya está en uso en la PBX: elija otro", c.AppCode)
	}
	appCode := c.AppCode
	if app != nil {
		appCode = app.Extension
	}

// PlanRemove lists every step Quitar takes to take callback off queues; when no queue keeps it, the
// shared IVR, app and file go too. The log is always kept.
func PlanRemove(st CallbackState, queues []string, dropWaiting bool) (CallbackPlan, error) {
	if len(queues) == 0 {
		return CallbackPlan{}, errors.New("elija al menos una cola")
	}
	app, ivr := st.CallbackApp(), st.CallbackIVR()
	selected := map[string]bool{}
	var steps []CallbackStep
	for _, ext := range queues {
		q := st.Queue(ext)
		if q == nil {
			return CallbackPlan{}, fmt.Errorf("la cola %s no existe en la PBX", ext)
		}
		if selected[ext] {
			continue
		}
		pr := st.Priority(*q)
		pa := st.PrioApp(pr)
		hooked := st.hooked(*q)
		if !hooked && pr == nil && pa == nil {
			return CallbackPlan{}, fmt.Errorf("la cola %s no tiene devolución de llamada", ext)
		}
		selected[ext] = true
		if hooked {
			steps = append(steps, step(StepDetach, ext, "", fmt.Sprintf("Cola %s · %s", ext, q.Description), queueNow(*q), "IVR: ninguno · membergosub: ninguno", false, ""))
		}
		if pa != nil {
			steps = append(steps, step(StepDelPrioApp, ext, pa.Extension, fmt.Sprintf("Aplicación %s «%s»", pa.Extension, pa.Description), "existe", "se elimina", false, ""))
		}
		if pr != nil {
			steps = append(steps, step(StepDelPriority, ext, "", fmt.Sprintf("Prioridad de cola «%s»", pr.Description), "existe", "se elimina", false, ""))
		}
		if n := st.waiting(ext); dropWaiting && n > 0 {
			steps = append(steps, step(StepDropWaiting, ext, "", "Devoluciones pendientes de la cola "+ext, fmt.Sprintf("%d pendiente(s)", n), "se descartan", false, ""))
		}
	}
	var routes []CallbackRoute
	users := 0
	for _, q := range st.Queues {
		if selected[q.Extension] || !st.hooked(q) {
			continue
		}
		users++
		if pa := st.PrioApp(st.Priority(q)); pa != nil && st.Attached(q) {
			routes = append(routes, CallbackRoute{Queue: q.Extension, App: pa.Extension})
		}
	}
	plan := CallbackPlan{Remove: true, DropWaiting: dropWaiting, Queues: queues, Routes: routes}
	if users == 0 {
		if ivr != nil {
			steps = append(steps, step(StepDelIVR, "", "", "IVR «"+ivr.Description+"»", "existe", "se elimina", false, ""))
		}
		if app != nil {
			steps = append(steps, step(StepDelApp, "", app.Extension, fmt.Sprintf("Aplicación %s «%s»", app.Extension, app.Description), "existe", "se elimina", false, ""))
		}
		if st.FileExists {
			steps = append(steps, step(StepDelFile, "", "", "Archivo extensions__65-callback.conf", "existe", "se elimina", false, ""))
		}
	} else {
		c, ok := ParseCallbackConfig(st.File)
		if !ok {
			return CallbackPlan{}, errors.New("el archivo de devolución de llamada no tiene su configuración (¿editado a mano?): instálelo de nuevo antes de quitar colas")
		}
		plan.Config = c
		plan.Dialplan = CallbackDialplan(c, st.RecordingPath(c.Recording), routes)
		if st.File != plan.Dialplan || st.Contexts != 3 {
			steps = append(steps, fileStep(st, plan.Dialplan))
		}
	}
	plan.Steps = steps
	return plan, nil
}

// VerifyCallback stamps each applied step from the read-back st: a step whose effect is not there fails.
func VerifyCallback(plan CallbackPlan, steps []CallbackStep, st CallbackState) []CallbackStep {
	out := append([]CallbackStep(nil), steps...)
	for i, s := range out {
		if s.Status != CbApplied {
			continue
		}
		q := st.Queue(s.Queue)
		var pr *CallbackPriority
		if q != nil {
			pr = st.Priority(*q)
		}
		ok := true
		switch s.Kind {
		case StepFile:
			ok = st.FileExists && st.File == plan.Dialplan && st.Contexts == 3
		case StepLog:
			ok = st.LogOwner == "asterisk"
		case StepApp:
			ok = st.CallbackApp() != nil
		case StepIVR:
			ok = st.CallbackIVR() != nil
		case StepPriority:
			ok = pr != nil
		case StepPrioApp:
			pa := st.PrioApp(pr)
			ok = pa != nil && pa.Extension == s.Code
		case StepQueue:
			ok = q != nil && st.Attached(*q)
		case StepDetach:
			ok = q != nil && !st.hooked(*q)
		case StepDelPrioApp:
			ok = st.PrioApp(pr) == nil
		case StepDelPriority:
			ok = pr == nil
		case StepDropWaiting:
			ok = st.waiting(s.Queue) == 0
		case StepDelIVR:
			ok = st.CallbackIVR() == nil
		case StepDelApp:
			ok = st.CallbackApp() == nil
		case StepDelFile:
			ok = !st.FileExists && st.Contexts == 0
		}
		if !ok {
			out[i].Status = CbFailed
			if plan.Remove {
				out[i].Error = "sigue en la PBX después de quitar"
			} else {
				out[i].Error = "no se encontró después de aplicar"
			}
		}
	}
	return out
}

// RunCallback runs the plan's steps in order. Steps planned as omitir are not run; the first failure
// stops the run and every later step stamps no_ejecutado. progress gets the number of steps finished.
func RunCallback(ctx context.Context, plan CallbackPlan, do func(context.Context, CallbackStep) error, progress func(done int)) []CallbackStep {
	out := append([]CallbackStep(nil), plan.Steps...)
	failed := false
	for i := range out {
		switch {
		case out[i].Status == CbSkip:
			out[i].Status, out[i].Error = CbSkipped, "ya estaba así"
		case failed:
			out[i].Status, out[i].Error = CbNotRun, "no se ejecutó: falló un paso anterior"
		default:
			if err := do(ctx, out[i]); err != nil {
				out[i].Status, out[i].Error, failed = CbFailed, Describe(err), true
			} else {
				out[i].Status = CbApplied
			}
		}
		progress(i + 1)
	}
	return out
}
```

```go
func verifyContexts(want bool) string {

		cond = `&& { echo "el contexto $c sigue cargado" >&2; exit 1; }`
	}

}

// InstallCallbackFile writes content (on stdin) next to the target under a name the include glob
// skips, moves it into place, reloads the dialplan and proves the 3 contexts are loaded.
func InstallCallbackFile(ctx context.Context, p Profile, sec Secrets, content string) error {
	cmd := `set -e; t=$(mktemp); trap 'rm -f "$t"' EXIT; cat > "$t"; ` +
		`install -o asterisk -g asterisk -m 644 "$t" ` + callbackFile + `.f03tmp; ` +
		`mv -f ` + callbackFile + `.f03tmp ` + callbackFile + `; ` +
		`asterisk -rx 'dialplan reload' > /dev/null; ` + verifyContexts(true)
	if _, err := SSHExec(ctx, p, sec.SSH, sec.SSHKey, cmd, strings.NewReader(content)); err != nil {
		return fmt.Errorf("no se pudo instalar el archivo de devolución de llamada: %w", err)
	}
	return nil
}

// EnsureCallbackLog creates the log with 2 header lines only when it is missing (the article: FILE()
// needs at least 2 lines), and gives it to asterisk. An existing log is never truncated.
func EnsureCallbackLog(ctx context.Context, p Profile, sec Secrets) error {

		`; chown asterisk:asterisk ` + callbackLog + `; chmod 644 ` + callbackLog
	if _, err := SSHExec(ctx, p, sec.SSH, sec.SSHKey, cmd, nil); err != nil {
		return fmt.Errorf("no se pudo preparar el registro: %w", err)
	}

// DropCallbacks discards the callbacks waiting on queue: their AstDB keys and their .call files
// still in the spool root (files already in outgoing/ belong to Asterisk and are left alone).
func DropCallbacks(ctx context.Context, p Profile, sec Secrets, queue string) error {
	if !reDigits.MatchString(queue) {
		return fmt.Errorf("cola inválida «%s»", queue)
	}
	cmd := `set -e; i=$(asterisk -rx 'database get pbx instance' | sed -n 's/^Value: //p'); [ -n "$i" ]; ` +
		`for id in $(asterisk -rx "database show $i/callback/` + queue + `" | sed -n 's#^/[^/]*/callback/` + queue + `/\([0-9]*\.[0-9]*\) .*#\1#p'); do ` +
		`rm -f "/var/spool/asterisk/$id.call"; done; asterisk -rx "database deltree $i/callback/` + queue + `" > /dev/null`
	if _, err := SSHExec(ctx, p, sec.SSH, sec.SSHKey, cmd, nil); err != nil {
		return fmt.Errorf("no se pudieron descartar las devoluciones pendientes: %w", err)
	}
	return nil
}

var reTrunkMatch = regexp.MustCompile(`(?i)context '(trk-group-[^']+)'`)

// RouteCheck asks Asterisk whether an outbound route of cos-all (its ARS-all) accepts number, and returns
// the trunk group context that does. cos-all itself is useless here: its catch-all matches every number.
func RouteCheck(ctx context.Context, p Profile, sec Secrets, number string) (string, error) {
	if err := CheckDialNumber(number); err != nil {
		return "", err
	}
	out, err := SSHExec(ctx, p, sec.SSH, sec.SSHKey, `asterisk -rx "dialplan show `+number+`@ARS-all"`, nil)
	if err != nil {
		return "", fmt.Errorf("no se pudo revisar las rutas de salida: %w", err)
	}
	if m := reTrunkMatch.FindStringSubmatch(out); m != nil {
		return m[1], nil
	}
	return "", fmt.Errorf("ninguna ruta de salida acepta %s: revise el prefijo", number)
}
```

```go
func (pt *portal) call(ctx context.Context, fields [][2]string) (portalReply, error) {
	var body bytes.Buffer
	w := multipart.NewWriter(&body)
	for _, f := range append(fields, [2]string{"baseurl", pt.base}) {
		if err := w.WriteField(f[0], f[1]); err != nil {
			return portalReply{}, err
		}

		return portalReply{}, err
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, pt.base+"/", &body)
	if err != nil {
		return portalReply{}, err
	}
	req.Header.Set("Content-Type", w.FormDataContentType())
	r, err := pt.ajax(req)
	if err != nil {
		return r, err
	}
	if r.State != "success" {
		reason := r.Notification.Text
		if reason == "" {
			reason = r.State
		}
		return r, fmt.Errorf("el portal rechazó el cambio: %s", reason)
	}
	return r, nil
}
```

```go
func (cp *CallbackPortal) Close() { cp.pt.client.CloseIdleConnections() }

// queueSnapshot is one queue's row plus its CUSTOM params ("param:<name>"), compared around a save.
func queueSnapshot(ctx context.Context, p Profile, sec Secrets, id int) (map[string]string, error) {
	rows, err := MySQL(ctx, p, sec, fmt.Sprintf("SELECT * FROM ombu_queues WHERE queue_id = %d;", id))
	if err != nil {
		return nil, err
	}
	if len(rows) != 1 {
		return nil, fmt.Errorf("la cola %d no existe", id)
	}
	snap := rows[0]
	params, err := MySQL(ctx, p, sec, fmt.Sprintf("SELECT name, value FROM ombu_queue_params WHERE queue_id = %d;", id))
	if err != nil {
		return nil, err
	}
	for _, r := range params {
		snap["param:"+r["name"]] = r["value"]
	}
	return snap, nil
}

// queueChanges lists every difference between two snapshots except the two fields F-03 may change.
func queueChanges(before, after map[string]string) []string {
	keys := map[string]bool{}
	for k := range before {
		keys[k] = true
	}
	for k := range after {
		keys[k] = true
	}
	var out []string
	for k := range keys {
		if k != "ivr_id" && k != "param:membergosub" && before[k] != after[k] {
			out = append(out, fmt.Sprintf("%s: «%s» → «%s»", k, before[k], after[k]))
		}
	}
	sort.Strings(out)
	return out
}

// guardQueue runs save on queue q and fails if it changed anything but IVR and membergosub.
// The portal has already saved by then, so the message says exactly what to undo by hand.
func (cp *CallbackPortal) guardQueue(ctx context.Context, q CallbackQueue, save func() error) error {
	before, err := queueSnapshot(ctx, cp.p, cp.sec, q.ID)
	if err != nil {
		return err
	}
	if err := save(); err != nil {
		return err
	}
	after, err := queueSnapshot(ctx, cp.p, cp.sec, q.ID)
	if err != nil {
		return fmt.Errorf("no se pudo verificar la cola %s después de guardar: %w", q.Extension, err)
	}
	if d := queueChanges(before, after); len(d) > 0 {
		return fmt.Errorf("el portal cambió otros campos de la cola %s (revíselos en el portal): %v", q.Extension, d)
	}
	return nil
}

// CallbackStepRunner performs one plan step: SSH steps directly, portal steps through cp. Portal steps
// re-read the state first for the ids they need (the app id for the IVR entry, the priority id for its app).
func CallbackStepRunner(p Profile, sec Secrets, cp *CallbackPortal, plan CallbackPlan) func(context.Context, CallbackStep) error {
	return func(ctx context.Context, s CallbackStep) error {
		switch s.Kind {
		case StepFile:
			return InstallCallbackFile(ctx, p, sec, plan.Dialplan)
		case StepDelFile:
			return RemoveCallbackFile(ctx, p, sec)
		case StepLog:
			return EnsureCallbackLog(ctx, p, sec)
		case StepDropWaiting:
			return DropCallbacks(ctx, p, sec, s.Queue)
		}
		st, err := ReadCallbackState(ctx, p, sec, nil)
		if err != nil {
			return err
		}
		var q *CallbackQueue
		if s.Queue != "" {
			if q = st.Queue(s.Queue); q == nil {
				return fmt.Errorf("la cola %s ya no existe", s.Queue)
			}
		}
		switch s.Kind {
		case StepApp:
			return cp.createCallbackApp(ctx, s.Code)
		case StepIVR:
			app := st.CallbackApp()
			if app == nil {
				return errors.New("falta la aplicación de devolución de llamada")
			}
			return cp.createCallbackIVR(ctx, plan.Config.Key, *app)
		case StepPriority:
			return cp.createPriority(ctx, *q, plan.Config.Priority)
		case StepPrioApp:
			pr := st.Priority(*q)
			if pr == nil {
				return fmt.Errorf("falta la prioridad de la cola %s", s.Queue)
			}
			return cp.createPrioApp(ctx, s.Code, *q, *pr)
		case StepQueue:
			iv := st.CallbackIVR()
			if iv == nil {
				return errors.New("falta el IVR de devolución de llamada")
			}
			return cp.guardQueue(ctx, *q, func() error { return cp.setQueue(ctx, *q, iv.ID, memberGosub) })
		case StepDetach:
			return cp.guardQueue(ctx, *q, func() error { return cp.setQueue(ctx, *q, 0, "") })
		case StepDelPrioApp:
			if pa := st.PrioApp(st.Priority(*q)); pa != nil {
				return cp.deleteApp(ctx, pa.ID)
			}
			return nil
		case StepDelPriority:
			if pr := st.Priority(*q); pr != nil {
				return cp.deletePriority(ctx, pr.ID)
			}
			return nil
		case StepDelIVR:
			if iv := st.CallbackIVR(); iv != nil {
				return cp.deleteIVR(ctx, iv.ID)
			}
			return nil
		case StepDelApp:
			if app := st.CallbackApp(); app != nil {
				return cp.deleteApp(ctx, app.ID)
			}
			return nil
		}
		return fmt.Errorf("paso desconocido «%s»", s.Kind)
	}
}
```

```go
import (
	"context"

// CallbackService is F-03: queue callback (Xorcom article) installed and removed on the active PBX.
type CallbackService struct {
	profiles *ProfileService
	mu       sync.Mutex
	last     *callbackRun // exactly what Apply runs: the last preview
}

type callbackRun struct {
	profileID string
	plan      pbx.CallbackPlan
}

// CallbackView is the Estado: the PBX state and the settings installed there (or the defaults).
type CallbackView struct {
	State     pbx.CallbackState       `json:"state"`
	Queues    []pbx.CallbackQueueView `json:"queues"`
	Config    pbx.CallbackConfig      `json:"config"`
	Installed bool                    `json:"installed"`
}

type CallbackPreview struct {
	Plan    pbx.CallbackPlan `json:"plan"`
	Route   string           `json:"route"` // install: the trunk group that accepts the test number
	New     int              `json:"new"`
	Skip    int              `json:"skip"`
	Blocked int              `json:"blocked"`
}

type CallbackResult struct {
	Folio   int                `json:"folio"`
	Steps   []pbx.CallbackStep `json:"steps"`
	Applied int                `json:"applied"`
	Skipped int                `json:"skipped"`
	Failed  int                `json:"failed"`
	NotRun  int                `json:"notRun"`
}

const (
	callbackReadTimeout  = 60 * time.Second
	callbackApplyTimeout = 5 * time.Minute
)

var errChanged = errors.New("la PBX cambió desde la vista previa: vuelva a generarla")

func (s *CallbackService) State() (CallbackView, error) {
	p, sec, err := s.profiles.active()
	if err != nil {
		return CallbackView{}, err
	}
	ctx, cancel := context.WithTimeout(context.Background(), callbackReadTimeout)
	defer cancel()
	st, err := pbx.ReadCallbackState(ctx, p, sec, pbx.CandidateCodes(pbx.DefaultCallbackConfig().AppCode))
	if err != nil {
		return CallbackView{}, errors.New(pbx.Describe(err))
	}
	c, ok := pbx.ParseCallbackConfig(st.File)
	if !ok {
		c = pbx.DefaultCallbackConfig()
	}
	return CallbackView{State: st, Queues: st.QueueViews(), Config: c, Installed: ok}, nil
}

func (s *CallbackService) PreviewInstall(c pbx.CallbackConfig, queues []string, testNumber string) (CallbackPreview, error) {
	p, sec, err := s.profiles.active()
	if err != nil {
		return CallbackPreview{}, err
	}
	if err := c.Validate(); err != nil {
		return CallbackPreview{}, err
	}
	ctx, cancel := context.WithTimeout(context.Background(), callbackReadTimeout)
	defer cancel()
	route, err := pbx.RouteCheck(ctx, p, sec, c.Prefix+testNumber)
	if err != nil {
		return CallbackPreview{}, errors.New(pbx.Describe(err))
	}
	st, err := pbx.ReadCallbackState(ctx, p, sec, pbx.CandidateCodes(c.AppCode))
	if err != nil {
		return CallbackPreview{}, errors.New(pbx.Describe(err))
	}
	plan, err := pbx.PlanInstall(st, c, queues)
	if err != nil {
		return CallbackPreview{}, err
	}
	return s.keep(p.ID, plan, route), nil
}

func (s *CallbackService) PreviewRemove(queues []string, dropWaiting bool) (CallbackPreview, error) {
	p, sec, err := s.profiles.active()
	if err != nil {
		return CallbackPreview{}, err
	}
	ctx, cancel := context.WithTimeout(context.Background(), callbackReadTimeout)
	defer cancel()
	st, err := pbx.ReadCallbackState(ctx, p, sec, nil)
	if err != nil {
		return CallbackPreview{}, errors.New(pbx.Describe(err))
	}
	plan, err := pbx.PlanRemove(st, queues, dropWaiting)
	if err != nil {
		return CallbackPreview{}, err
	}
	return s.keep(p.ID, plan, ""), nil
}

// keep stores the preview Apply will run and counts its lines.
func (s *CallbackService) keep(profileID string, plan pbx.CallbackPlan, route string) CallbackPreview {
	s.mu.Lock()
	s.last = &callbackRun{profileID: profileID, plan: plan}
	s.mu.Unlock()
	pv := CallbackPreview{Plan: plan, Route: route}
	for _, st := range plan.Steps {
		switch st.Status {
		case pbx.CbNew:
			pv.New++
		case pbx.CbSkip:
			pv.Skip++
		case pbx.CbBlocked:
			pv.Blocked++
		}
	}
	return pv
}

func (s *CallbackService) Apply() (CallbackResult, error) {
	p, sec, err := s.profiles.active()
	if err != nil {
		return CallbackResult{}, err
	}
	s.mu.Lock()
	run := s.last
	s.mu.Unlock()
	if err := run.check(p.ID); err != nil {
		return CallbackResult{}, err
	}
	ctx, cancel := context.WithTimeout(context.Background(), callbackApplyTimeout)
	defer cancel()
	// Re-plan against a fresh read: write exactly what was previewed, or nothing.
	codes := pbx.CandidateCodes(run.plan.Config.AppCode)
	if run.plan.Remove {
		codes = nil
	}
	st, err := pbx.ReadCallbackState(ctx, p, sec, codes)
	if err != nil {
		return CallbackResult{}, errors.New(pbx.Describe(err))
	}
	fresh, err := replan(st, run.plan)
	if err != nil || !sameSteps(run.plan, fresh) {
		return CallbackResult{}, errChanged
	}
	cp, err := pbx.OpenCallbackPortal(ctx, p, sec)
	if err != nil {
		return CallbackResult{}, errors.New(pbx.Describe(err))
	}
	defer cp.Close()
	folio, err := s.profiles.NextFolio()
	if err != nil {
		return CallbackResult{}, err
	}
	progress := func(done int) { application.Get().Event.Emit("callback:avance", done) }
	steps := pbx.RunCallback(ctx, run.plan, pbx.CallbackStepRunner(p, sec, cp, run.plan), progress)
	if after, err := pbx.ReadCallbackState(ctx, p, sec, nil); err == nil {
		steps = pbx.VerifyCallback(run.plan, steps, after)
	} else {
		for i := range steps {
			if steps[i].Status == pbx.CbApplied {
				steps[i].Status, steps[i].Error = pbx.CbFailed, "no se pudo verificar: "+pbx.Describe(err)
			}
		}
	}
	res := CallbackResult{Folio: folio, Steps: steps}
	for _, st := range steps {
		switch st.Status {
		case pbx.CbApplied:
			res.Applied++
		case pbx.CbSkipped:
			res.Skipped++
		case pbx.CbFailed:
			res.Failed++
		case pbx.CbNotRun:
			res.NotRun++
		}
	}
	s.mu.Lock()
	s.last = nil // done or stopped: the next Aplicar needs a fresh preview of what is there now
	s.mu.Unlock()
	return res, nil
}

func replan(st pbx.CallbackState, prev pbx.CallbackPlan) (pbx.CallbackPlan, error) {
	if prev.Remove {
		return pbx.PlanRemove(st, prev.Queues, prev.DropWaiting)
	}
	return pbx.PlanInstall(st, prev.Config, prev.Queues)
}

// sameSteps: the same steps in the same order with the same codes and statuses (texts may differ).
func sameSteps(a, b pbx.CallbackPlan) bool {
	if len(a.Steps) != len(b.Steps) || a.Dialplan != b.Dialplan {
		return false
	}
	for i := range a.Steps {
		x, y := a.Steps[i], b.Steps[i]
		if x.Kind != y.Kind || x.Queue != y.Queue || x.Code != y.Code || x.Status != y.Status {
			return false
		}
	}
	return true
}

// check refuses an Apply that would not run exactly what the user previewed, or that has nothing to do.
func (r *callbackRun) check(profileID string) error {
	if r == nil {
		return errors.New("no hay vista previa: genérela primero")
	}
	if r.profileID != profileID {
		return errors.New("la vista previa no corresponde a la PBX actual: genérela de nuevo")
	}
	n := 0
	for _, st := range r.plan.Steps {
		switch st.Status {
		case pbx.CbBlocked:
			return errors.New("hay pasos bloqueados: quite esas colas de la selección")
		case pbx.CbNew:
			n++
		}
	}
	if n == 0 {
		return errors.New("no hay cambios para aplicar: todo ya está así")
	}
	return nil
}
```

```ts
  let seq = 0
  onDestroy(() => seq++)
  async function load(manual = false) {
    const mine = ++seq
    discard()
    view = null
    viewError = ''
    if (!app.active) return
    reading = 'state'
    try {
      const v = await talk(CallbackService.State())
      if (mine !== seq) return
      view = v
      cfg = { ...v.config }
      picked = []
      if (manual) notify('ok', 'Estado leído de la PBX.')
    } catch (e) {
      if (mine !== seq) return
      viewError = errText(e)
      notify('fail', `No se pudo leer la PBX: ${errText(e)}`, 10000)
    } finally {
      if (mine === seq) reading = ''
    }
  }

  let shownPBX: string | null = null
  $effect(() => {
    const id = app.active
    if (id !== shownPBX) {
      shownPBX = id
      untrack(() => load())
    }
  })

  async function runPreview() {
    if (!cfg || picked.length === 0) return
    reading = 'preview'
    note = ''
    preview = null
    result = null
    try {
      preview = await talk(mode === 'install'
        ? CallbackService.PreviewInstall(cfg, picked, testNumber.trim())
        : CallbackService.PreviewRemove(picked, dropWaiting))
      if (preview.blocked) notify('fail', 'Hay pasos bloqueados en la vista previa: revise las colas marcadas en rojo.', 10000)
    } catch (e) {
      note = errText(e)
      notify('fail', `No se pudo preparar la vista previa: ${errText(e)}`, 10000)
    } finally {
      reading = ''
    }
  }

  async function apply() {
    if (!canApply) return
    app.busy = true
    applying = true
    done = 0
    note = ''
    const off = Events.On('callback:avance', (e) => (done = e.data as number))
    try {
      result = await talk(CallbackService.Apply())
      if (result.failed) notify('fail', `Folio ${result.folio}: ${result.failed} paso(s) fallaron. Revise las líneas en rojo.`)
      else notify('ok', `Folio ${result.folio}: ${result.applied} paso(s) aplicados.`)
      view = await talk(CallbackService.State())
    } catch (e) {
      note = errText(e)
      notify('fail', `No se pudo aplicar: ${errText(e)}`)
    } finally {
      off()
      applying = false
      app.busy = false
    }
  }

  function discard() {
    preview = null
    result = null
    note = ''
    portalMsg = ''
    confirmReload = false
    otherPending = null
  }

  // Same two-step portal Apply as F-02 (it reloads the whole PBX with every pending portal change).
  async function reloadPBX() {
    if (!confirmReload) {
      reading = 'pending'
      try { otherPending = await talk(ProfileService.PendingPortalChanges()) } catch { otherPending = null } finally { reading = '' }
      confirmReload = true
      setTimeout(() => (confirmReload = false), 8000)
      return
    }
    confirmReload = false
    app.busy = true
    reloading = true
    try {
      portalMsg = await talk(ProfileService.ApplyPortal())
      notify('ok', `PBX recargada: ${portalMsg}`)
    } catch (e) {
      portalMsg = errText(e)
      notify('fail', `No se pudo recargar la PBX: ${errText(e)}`)
    } finally {
      reloading = false
      app.busy = false
    }
  }
</script>
```
